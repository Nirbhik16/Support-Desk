# Support Desk

A full-featured customer support and ticket management platform.

## Tech Stack
- Backend: Spring Boot, PostgreSQL, Spring Security, JWT
- Frontend: React, Tailwind CSS (coming soon)

## Setup

### Prerequisites
- Java 17+
- PostgreSQL
- Maven

### Backend
1. Navigate to `/backend`
2. Create a PostgreSQL database named `supportdesk`
3. Update `application.properties` with your DB credentials
4. Run `mvn spring-boot:run`
